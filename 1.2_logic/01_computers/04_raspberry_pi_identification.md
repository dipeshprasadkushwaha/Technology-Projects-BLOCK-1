| Component | Function |
|-----------|----------|
| SoC |Processes data and runs instructions, acting as the main processor of the Raspberry Pi. |
| GPIO |Allows the Raspberry Pi to connect and communicate with electronic components such as sensors, LEDs and motors.|
| USB |Connect external devices such as a keyboard, mouse and USB drive. |
| HDMI |Connects the Raspberry Pi to a monitor or TV to display video and audio. |
| Power |Supplies electrical power to the Raspberry Pi so it can operate. |
| microSD |Holds the microSD card, which stores the operating system, programs and files. |
| Network |Connects the Raspberry Pi to a wired network or the internet. |
| Wireless |Allows wireless connections and communication with devices such as headphones, speakers and other compatible devices. |
